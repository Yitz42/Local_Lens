BUSINESS LISTINGS

Connect Google Maps.

Use Google’s business listings and map with Local Lens’s ownership and food filters. The connection applies to this browser.

Use a dedicated website-restricted key. It is sent to Google to load the map and search businesses. It stays in this browser, outside GitHub and this chat.

Set up your existing key

  1. Open Google Maps Platform → Credentials and select your project and API key.
  2. Under Application restrictions, choose Websites. Add https://local-lens-places.shrewdcow.chatgpt.site/*.
  3. Under API restrictions, allow Maps JavaScript API and Places API (New). Enable both APIs in your project and make sure billing is active.
  4. Save the restrictions, copy the key, and paste it above. Restrictions can take a few minutes to apply.

Google charges your project for map loads, searches, and saved-place refreshes, subject to its current free allowances. Set quotas in Google Cloud before connecting. Each area search makes up to five nearby requests, or one when a category or food type is selected.

Google limits each nearby request to 20 results. Results are a selection, and the ownership filters can reduce that selection. Google listings can still contain errors; they do not identify corporate or private-equity ownership.
